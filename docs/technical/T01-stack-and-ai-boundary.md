# T01 — تصمیم پشته فناوری و مرز هوش مصنوعی
وضعیت: APPROVED — تأیید کاربر در ۲۰۲۶-۱۰-۱۱
مخزن: kanoonyar
مبنای کسب‌وکار: B01–B05A

## تصمیم فناوری
- هسته عملیاتی Backend: C# و ASP.NET Core.
- Frontend: React + TypeScript، فارسی و RTL؛ سه محیط ستاد، پنل واحد کانون با سطوح مجوز، و پرتال مخاطب.
- پایگاه داده عملیاتی: PostgreSQL.
- هویت: Keycloak با OIDC؛ مجوزها باید در Backend و با دامنه کانون کنترل شوند.
- معماری اولیه: Modular Monolith با مرزهای دامنه و قراردادهای مستقل، روی بستر مشترک چندمستاجری برای ۸۰ کانون.
- هوش مصنوعی: Python + PyTorch، به‌عنوان زیرسامانه تخصصی مجزا از هسته عملیاتی و تحت کنترل کانون‌یار.
- نسخه دقیق .NET، کتابخانه‌های ORM، ارتباط بین هسته و AI، روش استقرار و ظرفیت سخت‌افزار هنوز باید در Technical تعیین و مستند شوند.

## نقش AI
- پیشنهاد محتوا، صفحه و طرح پویش؛ کمک به طراحی آموزش، برنامه بومی، تحلیل گزارش و راهنمایی مخاطب در حدود مجوز.
- AI دستیار است، نه مرجع مستقل تصمیم. انتشار محتوا، تغییر اهداف برنامه ملی، تأیید مالی، پرداخت/تسویه، صدور احکام ارزیابی و تغییر مجوز کاربران نیازمند اختیار معتبر انسانی‌اند.
- AI فقط به داده‌های مجاز و حداقل لازم دسترسی دارد؛ اطلاعات کودکان و نوجوانان نیازمند کنترل‌های خاص حریم خصوصی و مبنای قانونی معتبر است.
- یادگیری از داده عملیاتی خودکار و بی‌قید نیست: داده مجاز → پالایش/بازبینی → Dataset نسخه‌دار → آموزش → ارزیابی مستقل → تأیید انسانی → انتشار کنترل‌شده مدل.
- مدل پایه، الگوریتم/روش تنظیم، سخت‌افزار، شاخص‌های ارزیابی و روش اتصال AI به Backend هنوز انتخاب نشده‌اند؛ هیچ سرویس خارجی یا مدل مشخصی از این تصمیم استنباط نمی‌شود.

## پیامدها
- API و منطق عملیاتی در .NET باقی می‌ماند؛ Python مالک قواعد کسب‌وکار، مجوزها یا داده مرجع نیست.
- طراحی و پیاده‌سازی بر اساس Business → Technical → Backlog → Sprint → Code → Review → Stage → QA → Release Approval → Production → Monitoring → Improvement پیش می‌رود.
- این تصمیم انتخاب فناوری است، نه ادعای تکمیل معماری تفصیلی یا آمادگی Production.
