# Kanoonyar AI Foundation

This is a **non-operational** Python package. It provides only proposal-shaped contract examples and unit tests. It does not download a model, train, infer with a model, access production data, call external APIs, or modify official application state.

Run locally with Python 3.11+:

```sh
cd ai
python -m pip install -e .
python -m unittest discover -s tests -v
```

PyTorch is an approved future technology, not a runtime dependency of this skeleton. The real AI transport, model, evaluation and governance remain undecided.
