# کانون‌یار | KanoonYar

پلتفرم یکپارچهٔ کشوری برای مدیریت، توانمندسازی و ارزیابی کانون‌های فرهنگی.

## وضعیت فعلی

- کد پروژه تا **Sprint 116** در شاخهٔ `main` ادغام شده است.
- سامانه برای پوشش همهٔ **۸۰ کانون** و سه تجربهٔ وبِ پنل کانون، پنل ستاد و پرتال مخاطبان طراحی می‌شود.
- طراحی در Figma هنوز انجام نشده است.
- استقرار در Stage، اتصال به میزبان و سرویس OIDC واقعی، QA رسمی، انتشار و Production هنوز انجام نشده‌اند. وجود قابلیت در مخزن به معنی استقرار یا بهره‌برداری آن نیست.

## اصول پایه

- پوشش همهٔ ۸۰ کانون از افتتاح کشوری؛ نه عرضهٔ یک MVP ناقص.
- پلتفرم مشترک چندکانونی با استقلال اجرایی و پیکربندی محلی.
- ستاد برنامهٔ ملی را با اهداف و الزامات ثابت ابلاغ می‌کند؛ هر کانون طرح اجرای بومی مستقل دارد.
- فعالیت‌ها یک‌بار در محل اجرا ثبت می‌شوند و دادهٔ مجاز مبنای پایش و ارزیابی مرکز است.
- حفاظت از داده‌ها و مجوزهای مالی واقعی پیش‌شرط قابلیت‌های حساس‌اند.
- هیچ سیاست، امتیاز، آستانهٔ ارزیابی یا گردش تأیید نامصوبی فرض نمی‌شود.

## مسیر تولید

Business → Technical → Product Backlog → Sprint → Code → Code Review → Stage → QA/Testing → Release Approval → Production → Monitoring → Improvement

## اولویت فعلی کانون‌یار

۱. تثبیت CI و به‌روز نگه‌داشتن مستندات وضعیت.
۲. طراحی در Figma برای پنل کانون، پنل ستاد و پرتال مخاطبان.
۳. آماده‌سازی Stage، سپس QA رسمی و تصمیم‌گیری دربارهٔ انتشار.
